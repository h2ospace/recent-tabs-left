# Tabs Stay Left

タブを設定した秒数見続けると、左から指定した位置へ移動する Chrome 拡張機能。秒数を 0 にすると、切り替えた瞬間に移動します。位置は固定タブを除いて数えます。1番目は固定タブのすぐ右、2番目はその右のタブを1つ残してさらに右です。すでにその位置か、それより左にいるタブは動かしません。初期値は1番目です。ツールバーのアイコンをクリックするとオンとオフが切り替わり、オフのときはアイコンがグレーになります。オフのあいだは、タブの移動も、同じURLのタブへの移動も止まります。オンのあいだは、新しく開いたタブも同じ位置に出ます。

アドレスバーやブックマークで開いたURLが既にタブにあれば、新しいタブを作らずそのタブへ移ります。この動作も設定からオフにできます。

ウィンドウ内のタブが最大件数を超えて開かれると、新しく開いたタブは残し、一番右のタブを閉じます。固定タブは閉じません。初期値は20件です。

## 設定

ツールバーのアイコンはオンとオフの切り替えです。待機時間、移動位置、最大タブ数、同じURLのタブへ移動するかどうかは、`chrome://extensions` の「拡張機能のオプション」から変更します。初期状態はオン、待機時間3秒、左から1番目、最大タブ数20件です。同じURLのタブへ移動する設定は、拡張機能がオンのときだけ有効です。

## インストール

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオン
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択
4. 更新した場合は、同じ画面で再読み込みする
