# Recent Tabs Left

タブを設定した秒数見続けると、一番左（固定タブのすぐ右）へ移動する Chrome 拡張機能。秒数を 0 にすると、切り替えた瞬間に移動します。動作は設定からオフにできます。

## 設定

ツールバーのアイコンから開けます。初期状態はオン、3秒です。`chrome://extensions` の「拡張機能のオプション」からも同じ画面を開けます。

## インストール

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオン
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択
4. 更新した場合は、同じ画面で再読み込みする
